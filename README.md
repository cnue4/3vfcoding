# 三维狐少儿编程教务管理系统
# 官方网站：[3vf.cn](https://3vf.cn)
## 介绍
三维狐少儿编程教务管理系统是一套面向少儿编程培训机构的后台教务管理系统。
为提升少儿编程培训机构的教务管理效率，规范学生、课程、班级、课时、费用和教师结算等业务流程，三维狐少儿编程教务管理系统 V1.0 正式发布。本系统基于 ThinkPHP 和 FunAdmin 后台框架开发，采用 MySQL 数据库存储业务数据，围绕少儿编程培训机构的实际教务场景，设计并实现了一套较为完整的后台管理系统。
系统主要服务于培训机构管理员、教务人员和教师用户，可用于学生档案管理、试听体验课管理、续费报名管理、课程班级管理、课时记录、消课明细、调课补课停课、教师课时费统计、教师结算、费用预警、教案资料库、教具申请和校区联系簿等业务场景。
## 软件架构
本系统采用 B/S 架构设计，用户通过浏览器访问后台管理系统，服务器端负责业务逻辑处理和数据存储。
主要技术栈如下：
- 后端框架：ThinkPHP
- 后台框架：FunAdmin
- 数据库：MySQL 5.7
- Web 服务器：Nginx / Apache
- PHP 版本：PHP 8.1
- 前端技术：HTML、CSS、JavaScript、Layui
- 部署环境：Linux 服务器 / 宝塔面板
- 运行模式：浏览器 + Web 服务器 + PHP + MySQL
系统整体架构主要包括：
1. 表现层  
   负责后台页面展示、表单提交、数据列表展示和用户交互。
2. 控制层  
   负责接收用户请求，调用模型完成业务处理，并返回页面或 JSON 数据。
3. 业务层  
   负责学生管理、班级管理、课时消耗、教师结算、费用预警等核心业务逻辑。
4. 数据层  
   通过 MySQL 数据库存储学生、课程、班级、课时、费用、结算和系统权限等数据。

## 安装教程
### 1. 环境要求
请确保服务器或本地环境满足以下要求：
- PHP >= 8.1
- MySQL >= 5.7
- Nginx / Apache
- Composer
- PHP 扩展：fileinfo、mbstring、openssl、pdo_mysql、curl、gd 等
- 推荐使用宝塔面板进行部署
### 2. 上传源码
将系统源码上传到服务器网站根目录，例如：
```text
/www/wwwroot/code.ygz.ink/
如果使用本地环境，也可以放置到本地 Web 运行目录中。

3. 配置运行目录
请将网站运行目录设置为项目的 public 目录。

例如宝塔面板中：

网站设置 -> 网站目录 -> 运行目录 -> /public
4. 导入数据库
在 MySQL 中创建数据库，例如：

CREATE DATABASE codecrms_ygz_ink DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
然后导入项目中的数据库文件：

codecrms_ygz_ink.sql
5. 修改数据库配置
根据实际数据库账号和密码，修改项目数据库配置文件。

常见配置位置可能为：

.env
或：

config/database.php
请配置以下内容：

数据库地址：127.0.0.1
数据库端口：3306
数据库名称：codecrms_ygz_ink
数据库用户：你的数据库用户名
数据库密码：你的数据库密码
6. 安装依赖
在项目根目录执行：

composer install
如果服务器无法执行 Composer，可以在本地安装依赖后再上传完整项目。

7. 设置伪静态
如果使用 Nginx，可参考 ThinkPHP 的伪静态配置：

location / {
    if (!-e $request_filename) {
        rewrite ^(.*)$ /index.php?s=$1 last;
        break;
    }
}
8. 设置目录权限
确保以下目录具有写入权限：

runtime
public/upload
Linux 环境下可执行：

chmod -R 755 runtime public/upload
9. 访问后台
部署完成后，在浏览器中访问系统后台地址：

http://你的域名/coding.php
例如：

http://code.ygz.ink/coding.php
使用说明
1. 登录系统
使用管理员账号登录系统后台，进入教务管理系统首页。

2. 初始化基础数据
建议按照以下顺序维护基础数据：

管理员和教师账号
课程信息
班级信息
学生信息
3. 日常教务管理流程
日常使用中，可按照以下流程进行教务管理：

在学生管理中维护学生档案；
在课程管理中维护课程基础信息；
在班级管理中创建教学班级；
在课时管理中录入教师每次授课记录；
系统根据课时记录生成消课明细；
通过费用预警跟进剩余课时不足或欠费学生；
在教师课时费和教师结算中完成教师课时统计和结算。
4. 教师账号使用
教师账号登录后，只能查看自己负责班级相关的数据，包括：

自己负责的班级
自己班级下的学生
自己相关的课时记录
自己相关的消课明细
自己相关的费用预警和课时统计
5. 数据维护建议
定期备份数据库；
修改系统前建议备份源码；
删除业务数据前请确认是否影响课时和结算统计；
教师结算前应先确认课时记录和消课明细是否准确。
